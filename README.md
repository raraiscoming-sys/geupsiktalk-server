# 급식톡 카카오 스킬 서버 v4

## 핵심 변경점
- [학교등록] 버튼을 누르면 특정 학교가 아니라 학교명 입력 안내만 표시합니다.
- 사용자가 바로 `남천중학교`, `백양고등학교`처럼 입력하면 학교를 검색합니다.
- 같은 이름의 학교가 여러 지역에 있으면 지역/주소와 함께 번호 선택 버튼을 보여줍니다.
- 카카오 챗봇에서 자유 입력 학교명을 서버로 보내려면 `폴백/미인식 블록` 또는 학교명검색 블록을 급식조회스킬에 연결해야 합니다.

## Render 설정
Build Command: npm install
Start Command: npm start
Environment Variables:
- NEIS_API_KEY = 나이스 API 키
- NODE_ENV = production

## 카카오 챗봇에서 꼭 필요한 설정
1. 학교등록 블록: 급식조회스킬 연결
2. 사용자유형선택 블록: 급식조회스킬 연결
3. 학교선택번호 블록: 급식조회스킬 연결
4. 오늘/내일/이번주/저녁추천/장보기 블록: 급식조회스킬 연결
5. 가장 중요: 폴백 블록 또는 미인식 블록도 급식조회스킬에 연결
   - 그래야 사용자가 `남천중학교`처럼 자유롭게 입력한 학교명이 서버로 전달됩니다.
