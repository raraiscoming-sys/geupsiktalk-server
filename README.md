# 급식톡 카카오 스킬 서버 final v3

## 핵심 변경

- [학교등록] 버튼을 눌러도 특정 학교가 고정으로 등록되지 않습니다.
- 사용자가 직접 학교명을 입력하면 서버가 학교를 검색합니다.
- 이름이 같은 학교가 여러 개 나오면 지역/주소를 함께 보여주고 `1번`, `2번` 버튼으로 선택합니다.
- 예: 백양고등학교가 여러 지역에 있으면 목록에서 선택합니다.

## GitHub에 올릴 파일

- package.json

## Render 설정

- Build Command: npm install
- Start Command: npm start
- Environment Variable: NEIS_API_KEY = 나이스 API 키
- Environment Variable: NODE_ENV = production

## 카카오 챗봇에서 반드시 추가할 블록

학교등록 버튼을 누른 뒤 사용자가 `백양고등학교`처럼 학교명만 입력하면, 카카오 챗봇이 이 말을 서버로 보내야 합니다. 그래서 아래 둘 중 하나가 필요합니다.

### 추천: 학교명검색 블록 만들기

블록 이름: 학교명검색

사용자 발화 예시:
- 백양고등학교
- 동평중학교
- 서울고등학교
- 부산중학교
- 중앙초등학교
- 백양고
- 동평중
- 서울고
- 학교검색

설정:
- 파라미터 설정: 급식조회스킬
- 봇 응답: 스킬데이터 사용

### 더 좋은 방법: 폴백/기타 입력 블록이 있다면 연결

카카오 챗봇 관리자센터에서 `폴백 블록`, `기타 입력`, `알 수 없는 발화` 같은 기본 블록을 제공한다면 그 블록도 급식조회스킬에 연결하면 사용자가 입력한 학교명을 더 잘 받을 수 있습니다.

## 선택 번호 블록도 추가 권장

학교 검색 결과에서 `1번`, `2번` 버튼을 누르면 그 문장이 챗봇에 입력됩니다.
따라서 아래 블록도 만들어주세요.

블록 이름: 학교선택번호

사용자 발화 예시:
- 1번
- 2번
- 3번
- 4번
- 5번
- 1
- 2
- 3
- 4
- 5

설정:
- 파라미터 설정: 급식조회스킬
- 봇 응답: 스킬데이터 사용

## 테스트 순서

1. 처음
2. 학교등록 버튼 클릭
3. 백양고등학교 입력
4. 검색 결과에서 부산/경기 등 지역과 주소 확인
5. 1번 또는 2번 선택
6. 학생 또는 학부모 선택
7. 오늘 / 내일 / 이번주 테스트
