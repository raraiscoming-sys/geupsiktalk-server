# 급식톡 카카오 챗봇 스킬 서버 v2

## Render 설정

- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`

## Environment Variables

- `NEIS_API_KEY`: 나이스 Open API 인증키
- `NODE_ENV`: `production`

## 확인 주소

- `/` : 서버 실행 확인
- `/health` : 환경변수 확인
- `/skill` : 카카오 챗봇 스킬 POST URL

## 카카오 챗봇 스킬 URL 예시

`https://서비스이름.onrender.com/skill`
