# 급식톡 카카오 스킬 서버 Final v5

## 변경사항

- 학교 검색 실패 안내 문구를 개선했습니다.
  - `00여중`처럼 약칭으로 검색했을 때, `00여자중학교`처럼 정식 학교명으로 다시 검색하라는 안내가 나옵니다.
- 학교등록 안내 문구에도 정식 학교명 입력 안내를 추가했습니다.
- 학부모 모드에서 급식 조회 결과 아래에 저녁 추천과 장보기 목록이 함께 표시되므로, 기본 빠른응답 버튼에서 `저녁추천`, `장보기` 버튼을 제거했습니다.
- 기본 버튼은 `오늘 급식`, `내일 급식`, `이번 주 급식`, `학교 변경` 중심으로 정리했습니다.

## Render 설정

Build Command:

```bash
npm install
```

Start Command:

```bash
npm start
```

Environment Variables:

```text
NEIS_API_KEY=나이스_API_키
NODE_ENV=production
```

## 카카오 챗봇 연결

스킬 URL은 Render 주소 뒤에 `/skill`을 붙여 입력합니다.

```text
https://your-service.onrender.com/skill
```

## 권장 블록

스킬 연결 권장 블록:

- 학교등록/학교변경
- 학교명검색 또는 미인식/폴백 블록
- 학교선택번호
- 사용자유형선택
- 오늘 급식
- 내일 급식
- 이번 주 급식
- 설정 도움말

`저녁추천`, `장보기` 블록은 더 이상 필수는 아닙니다. 학부모 모드에서는 급식 조회 결과에 자동으로 포함됩니다.
