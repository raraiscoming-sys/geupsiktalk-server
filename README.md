# 급식톡 카카오 챗봇 스킬 서버 v4

## Render 설정

- Build Command: `npm install`
- Start Command: `npm start`

## Environment Variables

- `NEIS_API_KEY`: 나이스 Open API 인증키
- `NODE_ENV`: `production`

## 테스트

배포 성공 후 브라우저에서 아래 주소 확인:

- `https://본인주소.onrender.com/`
- `https://본인주소.onrender.com/skill`
- `https://본인주소.onrender.com/test?school=백양고등학교`

카카오 챗봇 스킬 URL:

- `https://본인주소.onrender.com/skill`
