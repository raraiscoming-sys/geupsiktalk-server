# 급식톡 Supabase 서버 v9 - 주간 급식 상세표시 비교버전

이번 버전은 v8 속도개선/캐시 버전을 기준으로, 이번 주/다음 주 급식표도 오늘/내일 급식처럼 더 자세히 표시하도록 수정한 비교용 버전입니다.

## 주요 변경

- 오늘/내일 급식: 기존과 동일하게 식판 이모지, 칼로리, 알레르기 요약 표시
- 이번 주/다음 주 급식: 날짜별로 조식/중식/석식을 구분해 표시
- 주간 급식에서도 메뉴 뒤 알레르기 번호 유지
- 주간 급식에서도 칼로리 표시
- 주간 급식에서도 해당 급식에 포함된 알레르기 요약 표시
- Supabase 저장, 한국시간 기준 날짜, 캐시 속도개선 기능 유지

## 적용 방법

GitHub 저장소에 아래 3개 파일을 업로드해 기존 파일과 교체합니다.

- package.json
- server.js
- README.md

그다음 Render에서 자동 배포를 확인하거나, 필요하면 Manual Deploy → Deploy latest commit을 실행합니다.

## 테스트

카카오톡 챗봇에서 다음 명령어를 확인하세요.

- 오늘
- 내일
- 이번주
- 다음주

이번주/다음주 급식표가 기존보다 길게 표시되므로, 실제 사용자 화면에서 가독성을 비교해보는 용도입니다.
