# 급식톡 Supabase 서버 v12

## 변경 내용
- 이번주/다음주 급식표를 한 말풍선에 모두 담지 않고 날짜별 여러 말풍선으로 나누어 전송합니다.
- 주간 급식은 메뉴 뒤 알레르기 번호와 칼로리까지만 표시합니다.
- 오늘/내일 급식, Supabase 저장, 한국 날짜 기준, 속도 캐시는 기존 기능을 유지합니다.

## 적용
1. package.json, server.js, README.md를 GitHub 저장소에 업로드합니다.
2. Render가 자동 배포되지 않으면 Manual Deploy → Deploy latest commit을 누릅니다.
3. 카카오톡에서 이번주/다음주를 테스트합니다.


## v14 변경사항
- `이번주`, `다음주` 입력 시 월~금 전체 급식을 한 번에 출력하지 않고 요일 선택 버튼을 제공합니다.
- 사용자가 `이번주 월요일`, `다음주 금요일` 같은 버튼을 누르면 해당 날짜 급식을 오늘/내일처럼 상세 표시합니다.
- 주간 급식 메시지 길이 제한 문제를 피하기 위한 버전입니다.

### 카카오 챗봇 블록 추가 권장
`요일선택` 블록을 만들고 아래 발화를 추가한 뒤 `급식조회스킬`에 연결하세요.
- 이번주 월요일, 이번주 화요일, 이번주 수요일, 이번주 목요일, 이번주 금요일
- 다음주 월요일, 다음주 화요일, 다음주 수요일, 다음주 목요일, 다음주 금요일
- 이번주 월, 이번주 화, 이번주 수, 이번주 목, 이번주 금
- 다음주 월, 다음주 화, 다음주 수, 다음주 목, 다음주 금


## v15 변경사항
- 이번주/다음주 요일 선택 화면에서 [메뉴] 버튼을 제거했습니다.
- 월요일~금요일 및 오늘 급식 버튼은 유지됩니다.
