급식톡 카카오 챗봇 스킬 서버 v1
=================================

이 파일은 카카오톡 채널 챗봇에서 아래 명령어를 처리하는 서버입니다.

지원 명령어
- 학교등록 백양고등학교
- 학생 / 학부모
- 오늘
- 내일
- 이번주
- 저녁추천
- 장보기
- 학교변경
- 설정

중요
- 카카오 챗봇 스킬은 외부 HTTPS 서버 주소가 필요합니다.
- 이 서버를 Render, Railway, Fly.io, Vercel 같은 곳에 올린 뒤 URL을 카카오 챗봇 스킬에 등록해야 합니다.
- 나이스 API 키는 코드에 직접 넣지 않고 환경변수 NEIS_API_KEY에 넣어야 합니다.

로컬 실행 방법
1. Node.js 18 이상 설치
2. 이 폴더에서 터미널 열기
3. npm install
4. 환경변수 설정
   Windows PowerShell:
     $env:NEIS_API_KEY="본인_API키"
     npm start
   Mac/Linux:
     NEIS_API_KEY="본인_API키" npm start
5. http://localhost:3000/health 접속해서 {"ok":true}가 나오면 성공

카카오 챗봇 스킬 URL
- 배포 후 아래 주소를 카카오 챗봇 스킬 URL로 등록하세요.
  https://배포주소/skill

카카오 챗봇 관리자센터에서 할 일
1. 스킬 만들기
2. URL에 https://배포주소/skill 입력
3. 학교등록/오늘/내일/이번주 블록에 이 스킬 연결
4. 테스트 채팅창에서 "학교등록 백양고등학교" 입력

주의
- 무료 서버는 일정 시간 사용하지 않으면 잠들 수 있습니다.
- users.json 파일에 사용자별 학교 정보가 저장됩니다. 정식 서비스에서는 DB로 바꾸는 것이 좋습니다.
